# College Java

Simple Java programs for Assignments 1 to 13 from the Programming with Java lab manual.

## Run an assignment

From the project root, compile and run an assignment using its package name:

```text
javac -d . assignments/assignment01/Assignment01.java
java assignments.assignment01.Assignment01
```

Each assignment is independent and uses only standard Java classes. Assignment 12 demonstrates
user-defined packages, while assignment 13 demonstrates file creation, writing, and reading.
